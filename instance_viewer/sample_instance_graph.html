How it works

Nodes expect: { id, entity, attrs }. Label is auto‑derived from entity + a few attrs (e.g., sample_name, site_name, etc).
Edges expect: { source, target, rel }. Edges with missing source/target are dropped.
Layout: Dagre (directed). Drag to rearrange; use Search to highlight matches. PNG export renders the current viewport.
