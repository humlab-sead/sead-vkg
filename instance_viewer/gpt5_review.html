How it works

Nodes expect: { id, entity, attrs }. Label is derived from entity + key attrs (e.g., sample_name, site_name).
Edges expect: { source, target, rel }. Edges missing source/target are dropped.
Layout: Dagre (directed). Drag to rearrange; use Search (⌘/Ctrl+F focuses) to highlight matches. PNG export can render viewport or the full graph; transparent background optional.
